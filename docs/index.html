Cairn overview

Cairn is a personal desktop assistant for macOS, in the style of ChatGPT Agent and Grok. A small animated avatar floats above your windows. Click it and ask for something: a reminder, a recurring task, a piece of research, a shopping comparison, or a job on your Mac. Each request runs in the background while you keep working, and anything risky waits for your approval. The brain is the Claude CLI (claude -p, using your own login). Web search is handled by Cairn's own transparent, robots.txt-respecting search and crawl engine, which the assistant uses as its search skill.

These are the real avatars, running live in this page. Choose one from the bubble's right-click Avatar menu. See every state in the avatar gallery or on the Floating bubble app page.

What the assistant does

Floating avatar bubble

A native Cairn.app puts a small animated avatar (about 88 px) above every window and on every Space. Drag it anywhere. Click it to open the chat panel, or press ⌥Space. The avatar shows at a glance whether Cairn is idle, working, waiting for you or offline. See Floating bubble app.

Always-on background tasks

Every request becomes a background run that keeps going after you close the panel. Up to three run at once and the rest queue. The Activity tab lists them, and a macOS notification tells you when each one finishes.

Reminders and recurring tasks

"Remind me to call Sam at 5pm", "every weekday at 8:30 summarise the news". The scheduler fires one-time reminders and recurring agent tasks, including tasks that run unattended. It can also add items to Reminders.app and Calendar.app when you ask.

Search and research

Quick answers and multi-step research with cited sources. Claude's web search is combined with Cairn's own index and its compliant, signed, audited fetcher.

Shopping with checkout hand-off

Asks what you need, compares products in a table (product, store, price, rating, link), keeps a shopping list and can add items to a cart. It never pays: it hands you the checkout link.

Computer tasks with approvals

Files, the terminal, Mac apps, the clipboard and a visible Playwright browser. Reading is automatic. Commands, file writes, clicks and form fills show an Approve / Deny / Always allow card first.

Claude CLI brain

claude -p --output-format stream-json with your Enterprise login, --resume for conversation memory, a per-run budget cap and a permission-prompt tool that routes every risky call to you.

Local and inspectable

One Node.js 20 process on 127.0.0.1 with zero npm dependencies. Conversations, runs, tasks and the shopping list are plain JSON files in the data directory.

The full catalogue, compared with ChatGPT Agent, ChatGPT Tasks and Grok, is on the Desktop assistant page. The feature table is in Feature catalogue.

The bubble and panel only talk to the local server. The server owns the agent, the approval queue and the scheduler. Quick start

Requirements: macOS, Node.js 20 or later, and the Claude CLI logged in (claude on PATH, or CAIRN_CLAUDE_BIN). Building the bubble also needs the Xcode Command Line Tools (swiftc). Without Claude, Cairn still crawls, indexes and searches, and gives extractive answers.

# 1. Start the server: web dashboard, assistant API and docs
$ node bin/cairn.js serve                  # → http://127.0.0.1:8787  (docs at /docs/, bubble UI at /web/bubble.html)

# 2. Install the floating bubble in /Applications, keep it in the Dock and start it (builds desktop/build/Cairn.app
#    if needed; --no-dock leaves the Dock alone); afterwards start it from the Dock, Spotlight (⌘Space › Cairn),
#    the Apps view / Launchpad, or: node bin/cairn.js desktop
$ node bin/cairn.js desktop --install

# 3. Run the whole test suite (node:test, loopback only)
$ npm test

# 4. Search-engine demo: start the Northwind Trails fixture site, crawl it,
#    search it and ask a quick question
$ node bin/cairn.js demo

# 5. Talk to the assistant from the terminal
$ node bin/cairn.js chat "Remind me to stretch in 20 minutes"

More commands (remind, tasks, approvals, shopping, assistant, and the engine commands crawl, ask, robots, doctor) are in the CLI reference.

Environment overrides: CAIRN_PORT, CAIRN_HOST, CAIRN_PUBLIC_URL, CAIRN_CONTACT, CAIRN_HOME (data directory), CAIRN_CLAUDE_BIN and CAIRN_MODEL. Engine settings are saved to data/config.json, and assistant settings (model, budget, working directory, browser, notifications, concurrency) to data/assistant-settings.json.

The search skill: Cairn's crawl engine

When the assistant searches or researches, it can use Cairn's own engine: a local, transparent, robots.txt-respecting web retrieval and answer engine. It crawls and indexes sites under an honest identity, answers questions with citations, and runs a research agent that can only reach the web through Cairn's compliant fetcher. The same engine is exposed to Claude as the cairn MCP server.

The engine copies the shape of the production AI bot families. OpenAI runs OAI-SearchBot, GPTBot and ChatGPT-User. xAI's crawler family covers training crawls, DeepSearch retrieval and user-triggered fetches. Anthropic runs ClaudeBot, Claude-SearchBot and Claude-User. Cairn follows the same pattern: one product with one robots.txt token per purpose, so a site owner can allow search, refuse dataset collection and decide separately about fetches that a person triggered.

  • A search indexer (CairnSearch) that crawls politely, follows sitemaps and honours robots.txt (RFC 9309), meta robots and X-Robots-Tag, then builds a local BM25 index.
  • A corpus collector (CairnCorpus) that writes JSONL datasets. Site owners can opt out of it without affecting search.
  • A user-triggered fetcher (Cairn-User) for the Ask view, the Fetch inspector and the research agent. Unlike ChatGPT-User or Google-Agent, it respects robots.txt by default.
  • An answer engine that retrieves passages and has the Claude CLI write a grounded, cited answer. If Claude is unavailable it falls back to an extractive answer.
  • A deep research agent: Claude CLI with every built-in tool disabled and exactly five MCP tools that proxy to Cairn's HTTP API. The agent is therefore bound by the same robots, rate-limit and audit rules as everything else.
  • A verifiable identity: requests carry HTTP Message Signatures (RFC 9421, Ed25519) per the IETF Web Bot Auth architecture, and the public keys are published at /.well-known/http-message-signatures-directory.

What Cairn is not

Not a stealth scraper

The search engine never spoofs a browser User-Agent, rotates IPs, solves CAPTCHAs or mimics browser fingerprints. See deliberately not implemented.

Not a hosted service

A single local Node.js process bound to 127.0.0.1, plus the bubble app. Tasks run only while your Mac is awake. It has no accounts and no multi-tenant isolation, and it is not meant to be exposed to a network.

The crawler is not a browser

The search engine runs no JavaScript and no headless Chrome. It fetches HTML and text, extracts them and indexes them. For interactive web tasks the assistant instead drives a visible Playwright browser on your Mac, and clicks or typing need your approval.

Not an access-control system

robots.txt is a request, not a lock. Cairn honours it, but that does nothing to stop other clients. See what is not protected.

The three crawler roles

How a question is answered

In both modes the model only sees text that Cairn retrieved, and it cites sources by the stable [n] ids that Cairn assigned. See Claude agent & MCP.

Highlights

Honest identity

Three role tokens, one family token, a +…/bot info URL, a From: contact header and IP range JSON files per role.

Independent opt-outs

Blocking CairnCorpus keeps a site out of datasets while leaving search untouched, in the same way GPTBot and OAI-SearchBot are separate.

RFC 9309 robots

Longest match wins and allow wins ties. Supports * and $, a 500 KiB parse limit, 4xx→allow and 5xx→disallow, and a stale copy on errors. Robots are rechecked on every redirect hop.

Polite by default

One request in flight per host, at least 1 s between requests, Crawl-delay honoured, and exponential backoff on 429/503 that respects Retry-After.

Page-level signals

Meta robots, bot-scoped <meta name="CairnSearch">, X-Robots-Tag (including the CairnSearch: noindex form), rel=nofollow, canonical links, noarchive and nosnippet.

Web Bot Auth

Requests are signed with Ed25519 (RFC 9421). The key directory is at /.well-known/http-message-signatures-directory and there is a verifier endpoint for site owners.

Cited answers

Retrieval over a BM25 index, grounded prompting and [n] citations, streamed over SSE. The extractive fallback works without Claude.

Contained research agent

Claude CLI runs with built-in tools disabled, five MCP tools, a spending cap, a timeout and an empty working directory.

Full audit trail

Every HTTP attempt, robots decision, crawl event and agent run goes to data/audit.ndjson, and a live stream is available in the UI.

Zero dependencies

Uses only node:* built-ins on Node.js 20 or later, with tests on node:test. There is no supply chain beyond Node and the Claude CLI.

Search engine commands

The engine works on its own, without the assistant. These commands drive it directly (the site-owner page is at http://127.0.0.1:8787/bot while serve runs):

$ node bin/cairn.js doctor           # node version, claude availability, data dir, signing key
$ node bin/cairn.js fixture --port 8788
$ node bin/cairn.js crawl http://127.0.0.1:8788/ --max-pages 30
$ node bin/cairn.js robots http://127.0.0.1:8788/private/secret.html
$ node bin/cairn.js ask "How much does the Ridgeback 45 weigh?"
$ node bin/cairn.js ask --deep "What is the return window and the pack warranty?"
$ node bin/cairn.js keys             # JWKS + keyid used for Web Bot Auth
